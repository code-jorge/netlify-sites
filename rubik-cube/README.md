## Rubik's Cube

Interactive 3D Rubik's Cube simulator built with React and Three.js.

### Features

- 3D cube with standard face rotations (R, L, U, D, F, B)
- Shuffle and reset
- Camera controls (orbit, zoom, reset)
- Multi-language support

### Getting started

```bash
npm install
npm run dev
```

### Tech stack

- React + Vite
- Three.js via React Three Fiber
